# 🎬 Grand CineVerse — 3D Procedural Cinema Hall (Three.js)

An interactive, high-fidelity 3D Cinema Hall built procedurally in **Three.js** using procedural geometry, dynamic canvas film playback, volumetric projector lighting, and Web Audio API spatial acoustics.

---

## 🌟 Live Demo
👉 **GitHub Pages:** [https://talent14-edu.github.io/3d-cinema-hall/](https://talent14-edu.github.io/3d-cinema-hall/)

---

## 🚀 Key Features

* **Procedural Architectural Design:**
  * 9-tier tiered seating platform with LED aisle safety edge strips.
  * Acoustic grooved side panels with architectural up/down sconce lights.
  * Ceiling acoustic baffles with soft downlights.
* **Plush Cinema Seats:**
  * 114 ergonomic velvet cinema seats with curved recliners, headrests, and armrests with cup holders (with soda cup props).
  * Real-time seat color customizer (Classic Red Velvet, Luxury Black Leather, Royal Navy, Emerald Green, Saddle Brown).
* **Curved IMAX Screen & Dynamic 4K Playback:**
  * Curved screen geometry facing the audience.
  * Real-time offscreen canvas video renderer featuring 4 cinematic streams:
    * 🌌 *Interstellar Sci-Fi Odyssey*
    * 🌆 *Cyberpunk 80s Synthwave*
    * ⏱️ *Classic Film Reel Countdown*
    * 🟢 *Matrix Digital Rain*
  * Real-time screen bounce lighting casting ambient movie hues over audience seats.
* **Volumetric Projector Light:**
  * High-mounted projection booth window with a dust-mote volumetric light cone shining over audience heads directly onto the screen.
* **Cinematic Sound Engine:**
  * Zero external audio files required — synthesizes a low-frequency 45Hz theater sub-bass rumble and projector cooling air hum via Web Audio API.
* **Camera Angles & View Modes:**
  * 🦅 **Overview:** Birds-eye perspective of the entire auditorium.
  * ⭐ **Sweet-Spot (Row 4):** The VIP acoustical center seat.
  * 🎬 **Front Row:** Low-angle immersive screen experience.
  * 👑 **Back Row:** High-tier perspective.
  * 📽️ **Projection Booth:** View from inside the projection room.
  * 🎭 **Stage to Audience:** Perspective from the stage looking up at the tiers.
* **Collapsible UI:**
  * Single-click toggle button and keyboard shortcut (`H`) for distraction-free movie viewing.

## 🛠️ Tech Stack
* **Three.js (r128)**
* **OrbitControls**
* **HTML5 Canvas 2D API** (Procedural Film Generator)
* **Web Audio API** (Procedural Theater Acoustics)
* **Tailwind / CSS3 Glassmorphism UI**
